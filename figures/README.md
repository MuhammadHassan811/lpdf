# Paper figures

The two figures in *"A Technique to Design Novel Protein Sequences Using Large
Language Models: A Unified Framework and Evaluation Protocol"* are generated by
these scripts rather than drawn by hand, so a change to the pipeline can be
reflected in the diagram by editing one line instead of redrawing an image.

| Script | Output | Figure |
|---|---|---|
| `fig1_pipeline.py` | `fig1_pipeline.png` | Fig. 1 — the eleven-stage LPDF pipeline |
| `fig2_conditional.py` | `fig2_conditional.png` | Fig. 2 — conditional generation |
| `diagram.py` | — | shared drawing helpers |

## Regenerating

```bash
pip install pillow
cd figures
python fig1_pipeline.py
python fig2_conditional.py
```

Both render at 2200 px wide, which is **320 DPI** at the 6.88 in text width of a
two-column IEEE page — comfortably above the 300 DPI that IEEE asks for.

The output is deterministic: regenerating on the same machine reproduces the
PNGs committed here byte for byte.

## Keeping the figures honest

Figure 1 is numbered to match the stage list in Section III-A of the paper. If a
stage is added, removed or renumbered, **both** must change. The earlier version
of this figure drifted out of step with the text — it showed reinforcement
learning as part of the pipeline when the paper lists RL as future work, and
omitted the filtering, novelty and ranking stages entirely. Generating the
figure from a script makes that drift easier to spot and cheaper to fix.

The stage numbers used in `fig1_pipeline.py` are:

| Badge | Stage |
|---|---|
| 1 | Corpora and preprocessing |
| 2 | Tokenization and embedding |
| 3 | Model adaptation |
| 4 | Conditional generation |
| 5 | Syntactic and biophysical filtering |
| 6a | ESMFold screen |
| 6b | AlphaFold2 confirm |
| 7 | Energy and stability |
| 8 | Homology search (novelty) |
| 9 | Functional plausibility |
| 10 | Multi-objective ranking |
| 11 | Masked re-sampling (refinement) |

Stages 6 to 9 are the four components of the ranking function, equation (14).

## Fonts

`diagram.py` looks for Arial, then Liberation Sans, then DejaVu Sans, across
Windows, macOS and Linux paths. If none is found it falls back to Pillow's
bitmap default and prints a warning; the figure will still render but the layout
will not match the published version, because text metrics differ.

## Notes on the drawing helpers

`diagram.py` is deliberately small — boxes, arrows, labels and notes, nothing
more. Two behaviours are worth knowing about:

- **Text auto-shrinks to fit its box.** Each line is measured and the font size
  reduced until it fits, down to a floor of 17 px. Lengthening a label will
  shrink it rather than overflow the box.
- **Text is kept clear of the stage badge.** The badge sits in the top-left
  corner, so the text block starts below it when a badge is present.
